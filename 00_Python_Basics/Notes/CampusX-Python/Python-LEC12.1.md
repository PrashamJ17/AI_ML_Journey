
ITERATORS AND GENERATORS 

Iterators - 

- Iteration - general term for taking each item , traversing through a sequence/group of items - like Loops
- Iterator - an object that allows the programmer to traverse through a sequence of data without having to store the entire data in memory 
- iterator object - eg x =  range(1,1000) -> this won't create a list , or a tuple ... , but it is an iterator object -> meaning only one item at a time will be in the memory when some opn is performed on x . then it loads other item in a sequencial manner -> range , at a time only one item is in memory so it takes very less space
