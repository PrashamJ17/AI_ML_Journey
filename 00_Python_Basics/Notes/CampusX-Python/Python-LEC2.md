1. **Operators** - 
	 - Arithmetic - + , - , * , / , // (int/floor division) (lower integer 5/2 = 2 (not 3))  , % (modulo (remainder)) , ** (exponential) 
	 - Relational - > , < , >= , <= , == , != 
	 - Logical - and , or , not ( False -> 0 , True -> 1 )
	 - Bitwise -binary no.s -  bitwise and (&), bitwise or( | ) , bitwise xor(^) , bitwise not (~), left shift(>>) , right shift(<<)
	 - Assignment - = , used in conjunction with other operators
	 - Membership - in , not in 

2. **if-elif-else -> conditional operators -> branching**
	- if(condn): 
		- statement
	- elif(condn): 
		- statement
	- else :
		- statement
	 - we can also have nested if-else 
	 - condition -> 1 means -> True , if condn -> 0 means -> False

4. **Loops** - 
	- for , while
	- used in case for repetitive codes/ structure - 
		- for eg . on websites like zomato , product based websites, when you scroll to see different products , all live in a similar container , displayed on the same grid , structure , just the information for each product is different. So , the code for the structure is looped , only the data fetched is different everytime . 
	- you can use else statements with loops as well 
	- while loop runs unti condn is false - can run infinitely
	- for loop runs until iterator out of range - definitive , increments/decrements automatically .
	- in for loop , we can use range(start,stop,step_size) function to run the loop 
	- range() -> can also run backwards -> eg - range(10,0,-1) 

5. **abs( )** --> gives only positive values of an expression , eg abs(5-10) = 5
